# -Getting-help-in-the-command-line
# Overview
- This focuses on how and where to get help on Linux right through the command line
# Learn more about commands
- whatis cat
# To get more details about cat, using man returns a general description of cat and information about each of it's options
- man cat
# using apropos to find a command that returns the first part of a file 
- apropos -a first part file
# Exploring the useradd command to find an option that can be used to set an expiration date for a temporary user account with useradd
- man useradd
# Exploring the rm and rmdir commands to identify which of the commands remove only empty directories 
- whatis rm
- whatis rmdir
# Determining which command to use to create a new group
- apropos -a create new group
